  3. Open it

    Because the file is unsigned and new, you'll see warnings. The exact words may differ on your PC.

    Your browser may say the file isn't commonly downloaded. Choose to keep it, and only for that notice. Then check the saved file in step 2.

    Windows may show “Windows protected your PC”. Only after step 2 printed True, choose More info, then Run anyway, and only for that screen.

    Stop and delete the file if your browser or a security product says it found malware or a virus, or if Windows asks for administrator permission in any form (a password or a Yes/No prompt): setup never needs it.

    These warnings mean Windows doesn't know the file yet, not that it found something wrong. A fake copy would bring the same warnings, which is why checking the fingerprint matters.

    If Smart App Control is on, Windows may block Petalock with no Run anyway option. This preview can’t run on that PC until Petalock is signed; we don’t suggest turning Smart App Control off for it.

What happens to your vaults

Installing

Petalock goes into your own user folder; no administrator needed. It makes no vault until you create one.

Updating

Install the new version over the old one. Your vaults, settings and “start with Windows” stay as they are. Petalock doesn’t update itself or tell you about new versions: check this page or the releases list.

Uninstalling

Removes the program and its temporary copies of opened files. Your vaults are never deleted, and nor are Petalock’s settings and list of vaults; the guide shows how to remove those too.

Going back

Older versions stay on the releases list. Setup lets you install one over a newer version, but going back hasn’t been tested: an older version may not open vaults or settings a newer one has changed, so keep a tested backup before you try. If a release is withdrawn, this page goes back to the last good one and the withdrawn release’s notes say why.

Deleting a vault on purpose

Petalock can't delete a vault for you yet. First note the vault's exact folder (in Petalock, choose Show in File Explorer). If you might want the vault back, make sure you have a tested backup you can restore. Then remove it from the list in Petalock, then delete that folder in File Explorer. Step by step in the guide.

What you need

Windows 11, 64-bit. Windows 10 (64-bit) should work but hasn't been tested.

Setup needs the internet only if your PC lacks Microsoft Edge WebView2, which Windows 11 includes: setup then gets it from Microsoft. Petalock has no online features: it sends nothing about you or your vaults anywhere.

Not offered yet

No code signature (Authenticode or PGP), no package managers and no automatic updates in this preview: the fingerprint above is how you check a file (the guide also shows GitHub’s build record).
